# ADR-0005: Rust host implementation with narrow native interfaces

Status: **Accepted**

Date: 2026-09-05

## Context

The host must manage untrusted IPC and asynchronous resource lifetimes, while interoperating with existing Linux/graphics APIs.

## Decision

Use Rust for CLI, helper, daemon, session, IPC and desktop backends. Use C/C++ FFI where required by LXC, graphics or Android APIs. Guest Shell/framework glue may use Java/Kotlin and Android NDK C++; choose language around the actual platform interface. Do not introduce Go without new evidence.

## Alternatives and consequences

Keep unsafe calls in small documented modules with OwnedFd/BorrowedFd and explicit GPU object lifetime. Do not aim for a percentage of Rust or reimplement mature native APIs. Avoid a giant common crate and create crates only when independent ownership/testing warrants it.

## Evidence and validation

[DEPENDENCIES.md](../DEPENDENCIES.md); M1 and [ADR-0015](0015-dependencies.md). Verify FFI behavior in focused integration tests before exposing safe wrappers.
