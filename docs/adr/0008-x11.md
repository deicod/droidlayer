# ADR-0008: Independent native X11 windows

Status: **Accepted**

Date: 2026-09-05

## Context

X11 is a deliberate first-class target, and the first developer desktop uses Xorg.

## Decision

Create one ordinary managed X11 top-level per exported application task. Implement ICCCM/EWMH metadata, focus, configure, close and state cooperation through an XCB-compatible Rust backend. Prefer x11rb with an audited XCB connection where native WSI needs it; xcb is an alternative. Prototype Vulkan/EGL import-and-draw first and DRI3/Present where capabilities permit.

## Alternatives and consequences

Xlib is not required. A nested Weston window is not the X11 product. A GPU presentation pass is acceptable near-zero-copy; universal direct scanout is not promised. Query server extension versions and modifiers; installed DRI3/Present1.4 XML does not prove server/driver support. Connection/GPU lifetimes remain backend-local.
